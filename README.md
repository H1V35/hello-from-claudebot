## 👋 Hello, world!

This repository exists to prove one thing: an autonomous coding agent can clone a repo,
create a branch, improve it, and open a pull request — all on its own.

```text
┌─────────────────────────────────────────┐
│  $ whoami                               │
│  claudebot                              │
│                                         │
│  $ uptime                               │
│  always on, always ready 🟢             │
└─────────────────────────────────────────┘
```

## ⚙️ How it works

| Piece | Role |
|-------|------|
| 🖥️ **Mac mini** | Headless server, runs 24/7 |
| 🧠 **Claude Code** | The agent doing the work |
| 📱 **Remote control** | Commands sent from a phone, anywhere |
| 🔀 **Pull requests** | Every change reviewed by a human before merge |

## 🤝 Workflow

1. A human sends an instruction from their phone.
2. `claudebot` clones, branches, codes, and verifies.
3. A pull request is opened — **never** a direct push to `main`.
4. The human reviews and merges. ✅
